All Kamen Rider: Rider Generation - English Translation Patch v1.1
=================================================================
Translation by me2suzuran

This patch translates the Japanese Nintendo DS game "All Kamen Rider: Rider Generation"
(Bandai Namco, 2011) into English.

What is translated
------------------
- All story dialogue (prologue, every boss conversation for every Rider, epilogue) and speaker names
- World map narration, stage names and missions
- Menus, buttons, dialogs, save messages, password screen, controls manual, legal notice
- Character select: Rider names, items, abilities and all move names
- In-stage HUD, tutorials, item/level-up banners, shop and shopkeeper lines
- Credits job titles (staff names are left in Japanese)

Not translated: game logos, series logos, company logos, and voice acting.

How to patch
------------
You need your own copy of the original Japanese ROM. This patch does not contain the game.

Required ROM:  All Kamen Rider - Rider Generation (Japan).nds
  Size:   67,108,864 bytes (64 MB)
  CRC32:  986B74F0
  MD5:    adc87f72d8f315bff1024635d4681f08
  SHA-1:  cc6a531acf0e325e242827673241ae2d6333391e

1. Open Rom Patcher JS in your browser: https://www.marcrobledo.com/RomPatcher.js/
   (or use Floating IPS / flips on PC)
2. Select the Japanese ROM as the ROM file.
3. Select "All Kamen Rider - Rider Generation (English) v1.1.bps" as the patch.
4. Apply the patch and save the new .nds file.

If the patcher says the checksum does not match, your ROM is a different dump or has already been
modified. Use a clean, unmodified copy.

Patched ROM:
  Size:   67,108,864 bytes (64 MB, same as the original)
  CRC32:  E77A8391

Do not trim the patched ROM: a few translated files are stored after the original data.

Real hardware / anti-piracy
---------------------------
The patched ROM keeps the original header, ARM9 layout and file positions, so loaders such as
TWiLight Menu++ / nds-bootstrap still recognise the game and apply their anti-piracy fix.
